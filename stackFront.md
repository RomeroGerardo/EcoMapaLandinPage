# Romero Labs Tech Stack

Tecnologías, paquetes y librerías que usamos a diario según el tipo de proyecto:

- **React** – Biblioteca principal para construir interfaces y componentes.
- **Tailwind CSS** – Framework de utilidades para estilos rápidos y altamente personalizables.
- **shadcn/ui** – Colección de componentes modernos y accesibles listos para usar.
- **React Router** – Manejo de rutas y navegación dentro de aplicaciones SPA.
- **TanStack React Query** – Control eficiente del fetching, caching y sincronización de datos.
- **Vite** – Herramienta de desarrollo súper rápida y ligera para proyectos modernos.
- **Axios** – Cliente HTTP para manejar solicitudes a APIs de manera simple.
- **TypeScript** – Tipado estático que ayuda a evitar errores y mejorar la mantenibilidad.
- **Zustand** – Estado global minimalista, simple y potente.
- **Swiper** – Carruseles y sliders con excelente performance y personalización.
- **Sonner** – Notificaciones elegantes, rápidas y fáciles de integrar.
- **date-fns** – Utilidades para manipular y formatear fechas sin complicaciones.
- **React Hook Form** – Manejo de formularios con performance y mínimo boilerplate.
- **Zod** – Validación y construcción de esquemas tipo-safe, ideal para formularios y APIs.

## Instrucciones para el Agente
Cuando trabajes en proyectos relacionados con este entorno, utiliza este stack tecnológico por defecto. Aplica cada herramienta para su propósito específico detallado arriba (por ejemplo, usar `Zustand` para el estado global, `TanStack React Query` para el data fetching, `Zod` con `React Hook Form` para formularios, etc.).
